# Aturan Alur Kerja Implementasi

## 1. Satu task dalam satu waktu
- Kerjakan task dari `tasks.md` secara berurutan, satu per satu.
- Kerjakan HANYA task yang saya minta. 
- Setelah satu task selesai, BERHENTI. Jangan lanjut ke task berikutnya
  sebelum saya memberi konfirmasi secara eksplisit (misalnya "lanjut").
  
## 2. Batasan teknologi
- Buat struktur dan implementasi langsung di folder project.
- Gunakan hanya stack yang sudah ditetapkan
- Jangan menambahkan framework, library, atau dependency baru tanpa
  persetujuan saya. Jika memang diperlukan,jelaskan alasannya dan tunggu konfirmasi.

## 3. Review dan revisi
- Lakukan maksimal SATU putaran review dan perbaikan terhadap hasil
  sendiri.
- Jika setelah satu putaran masih ada masalah, jangan terus mencoba.
  Laporkan masalahnya kepada saya beserta dugaan penyebabnya.
